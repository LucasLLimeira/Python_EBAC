# POO - Programação Orientada a Objetos

Este é um projeto de aprendizado do Git e GitHub, com foco em conceitos de Programação Orientada a Objetos (POO) em Python.

## Conteúdo

- `animais.py` — Exemplo de herança e polimorfismo com classes de animais
- `calculadora.py` — Calculadora implementada com POO
- `molde_poke.py` — Exemplo de modelagem de objetos inspirado em Pokémon
